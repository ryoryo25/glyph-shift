# GlyphShift — 英数字ランダム変換・類似文字ジェネレーター

入力された英数字列に対して、1文字ずつ以下の変換をランダムに適用し、生成された文字列の表示およびクリップボードへのワンクリックコピーを行うWebアプリケーションです。すべての変換処理はブラウザ内（ローカル）で完結し、外部サーバーへのデータ送信は一切行いません。

## 主な機能

1. **変換元文字列の入力**
   - 任意の英数字列をリアルタイムで変換します。サンプル文字列のワンクリック読み込みにも対応しています。
2. **変換モード・割合指定・変換リスト生成数指定**
   - **そのまま（原形維持）**: デフォルト重み `30%`
   - **大文字・小文字変換**: デフォルト重み `30%`（英字の大文字・小文字を反転 `A ↔ a`）
   - **Leet（似ている形の文字に変換）**: デフォルト重み `40%`（印字可能な半角ASCII文字のみ）
   - **変換リスト生成数**: デフォルト `5件`（`1〜10件` の範囲で指定可能）
3. **変換結果リスト**
   - 指定した件数のランダム変換候補を一覧表示し、各行の「コピー」ボタンで即座にクリップボードへコピーできます。
4. **変換ルール・インスペクタ（アコーディオン）**
   - 初期状態では折りたたまれたアコーディオン形式で配置されています。
   - 選択中の変換結果について、1文字ごとの変換ルール内訳を確認でき、文字セルをクリックすることでその1文字だけ変換パターン（そのまま → 大小変換 → 類似文字）を個別に切り替えられます。
5. **変換ルール一覧（アコーディオン）**
   - 初期状態では折りたたまれたアコーディオン形式で配置されています。
   - デフォルトの類似文字ルール（下記参照）の個別ON/OFF切り替えや、独自の半角ASCII類似文字ルールの追加（ブラウザの `localStorage` に保存）が可能です。

## デフォルトの類似文字（Leet / ASCII）変換ルール

| 元の文字 | 変換先候補 (ASCII) | 説明 |
| :--- | :--- | :--- |
| `O` / `o` | `0` | オーを数字のゼロに変換 |
| `l` | `1`, `\|`, `!` | 小文字エルを1、縦棒、感嘆符に変換 |
| `I` | `1`, `\|` | 大文字アイを1、縦棒に変換 |
| `S` / `s` | `5`, `$` | エスを5、ドル記号に変換 |
| `i` | `!`, `1`, `:` | 小文字アイを感嘆符、1、コロンに変換 |
| `A` / `a` | `4`, `@` | エーを4、アットマークに変換 |
| `E` / `e` | `3` | イーを3に変換 |
| `T` / `t` | `7`, `+` | ティーを7、プラス記号に変換 |
| `B` / `b` | `8`, `6` | ビーを8、6に変換 |
| `G` / `g` | `6`, `9`, `&` | ジーを6、9、アンパサンドに変換 |
| `Z` / `z` | `2`, `7` | ゼットを2、7に変換 |
| `q` | `9` | 小文字キューを9に変換 |
| `0` | `O`, `o` | 数字の0を英字のO、oに変換 |
| `1` | `l`, `I`, `!` | 数字の1をエル、アイ、感嘆符に変換 |
| `2` | `z`, `Z` | 数字の2を英字のz、Zに変換 |
| `5` | `S`, `s`, `$` | 数字の5をエス、ドル記号に変換 |
| `8` | `B`, `&` | 数字の8をB、アンパサンドに変換 |

## ローカル開発手順

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:3000)
npm run dev

# 単体テストの実行
npx --yes tsx --test src/utils/transformer.test.ts

# 本番用静的ファイルのビルド (./dist に出力)
npm run build
```

## GitHub Pages へのデプロイ手順

リポジトリには `.github/workflows/deploy.yml` が含まれており、`main`（または `master`）ブランチへのプッシュ時に自動で GitHub Pages へビルド・デプロイされます。

1. GitHub リポジトリの **Settings > Pages** を開きます。
2. **Build and deployment** の **Source** で **GitHub Actions** を選択します。
3. `main` ブランチへコードをプッシュするか、**Actions** タブから `Deploy to GitHub Pages` ワークフローを手動実行（`Run workflow`）すると公開されます。
